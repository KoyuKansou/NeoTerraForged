# How to build

Currently only support and tested on fabric, forge is NOT SUPPORTED

Mod may break with custom preset

pull request to fix or improve is welcomed

(but i personally fond of a proper port)

fix the placeholder text of the mod GUI

```
./gradlew fabric:runData
```

Compile the mod

```
./gradlew :fabric:build
```

(only do fabric jar mod compiling, doing full gradle build is not recommended)
